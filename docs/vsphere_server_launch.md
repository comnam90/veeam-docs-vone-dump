# Step 1. Launch Add Server Wizard


To launch the Add Server wizard:

1. Open Veeam ONE Web Client.

For details on accessing Veeam ONE components, see [Veeam ONE Web Client](access.md#access_web_client).

1. At the top right corner of the Veeam ONE Web Client window, click Configuration.
2. In the Data Collection section of the configuration menu, click Data source.
3. Click Add server.

You can also launch the Add Server wizard from Veeam ONE Client, to do so:

1. Open Veeam ONE Client.

For details on accessing Veeam ONE components, see [Veeam ONE Client](access.md#access_client).

1. In the main menu, click Add Server. You will be redirected to Veeam ONE Web Client to follow the wizard steps.

Alternatively, to access the Add Server wizard from Veeam ONE Client you can:

* Press [CTRL+I] on the keyboard.
* At the bottom of the inventory pane, open the Virtual Infrastructure view, right-click the Virtual Infrastructure node and choose Add Server from the shortcut menu.
