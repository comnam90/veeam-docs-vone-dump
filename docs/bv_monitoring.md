# Business View Monitoring


Veeam ONE Client allows you to monitor infrastructure presented from the business perspective — that is, based on Business View categories and groups of VMs, hosts, datastores, clusters, computers and enterprise applications.

With Veeam ONE, you can:

* Monitor the overall state of the categorized infrastructure
* View triggered alarms
* View objects included in categories and groups
* Work with performance charts
* View the list of events
