# Configuring Notification Settings


When you open Veeam ONE Client for the first time, you will be prompted to configure notification settings in the Notification Settings wizard.

|  |
| --- |
| Tip: |
| If you want to configure notification settings later, click Cancel.  To access the wizard later, in the main menu, select Notifications. Alternatively, you can configure notifications by changing server settings. For details, see [Veeam ONE Server Settings](server_settings.md). |

To configure notification settings, take the following steps.

1. [Configure SMTP server settings](notification_smtp_server.md).
2. [Configure email notification settings](notification_email.md).
3. [Configure email frequency](notification_frequency.md).
4. [Configure SNMP settings](notification_snmp.md).
5. [Configure Syslog Integration](notification_config_syslog_integration.md)
6. [Configure ServiceNow Integration](notification_configure_servicenow.md)
7. [Review summary](notification_review.md).
