# Step 14 Apply Available Updates


We recommend that you periodically check for Veeam ONE updates and install them as available. You can download product updates at [Latest Updates](https://www.veeam.com/products/downloads/latest-version.html).
You can also use the Check for Updates feature available via the Veeam ONE Web Client configuration menu. For details on Check for Updates, see [General Configuration Details](view_general_config_details.md).
