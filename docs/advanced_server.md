# Installing Veeam ONE Server


To install Veeam ONE Server, follow these steps:

1. [Launch Splash Window](advanced_launch_splash.md).
2. [Select Component](advanced_install_veeamone.md).
3. [Accept License Agreements](advanced_accept_license_agreement.md).
4. [Choose License Method](advanced_license_method.md).
5. [Specify Service Account Credentials](advanced_specify_service_account.md).
6. [Perform System Configuration Check](advanced_perform_configuration_check.md).
7. [Review Installation Summary](advanced_review_original_summary.md).
8. [Select Architectural Components](advanced_choose_components.md).
9. [Choose Monitoring Database](advanced_choose_sql.md).
10. [Choose Reporting Database](custom_choose_postgres.md).
11. [Choose Data Location](advanced_install_path.md).
12. [Choose Data Collection Mode](advanced_choose_collection_mode.md).
13. [Specify Connection Ports](advanced_choose_ports.md).
14. [Review Installation Summary](advanced_review_summary.md).
15. [Add Veeam ONE Service Account to Veeam ONE Administrators Group](advanced_check_admins_group.md).
