# Veeam Backup for Microsoft 365 Summary Dashboards


Veeam Backup for Microsoft 365 summary dashboards serve as the 'launch point' for monitoring the backup infrastructure and data protection operations. The dashboards reflect the latest state of backup jobs, and help you analyze the performance and configuration of backup infrastructure components.

Veeam ONE Client offers the following types of summary dashboards for Veeam Backup & Replication infrastructure components:

* [Veeam Backup for Microsoft 365 Infrastructure Summary](vbo_server_summary.md)
* [Veeam Backup for Microsoft 365 Repositories Overview](vbo_repositories_summary.md)
* [Veeam Backup for Microsoft 365 Repository Summary](vbo_repository_overview.md)
* [Veeam Backup for Microsoft 365 Proxies Overview](vbo_proxies_overview.md)
* [Veeam Backup for Microsoft 365 Proxy Summary](vbo_proxy_summary.md)
* [Veeam Backup for Microsoft 365 Proxy Pools Summary](vbo_proxy_pools_summary.md)
