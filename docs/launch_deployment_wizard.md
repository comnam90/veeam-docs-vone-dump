# Step 1. Launch Add Deployment Project Wizard


To launch the Add Deployment Project wizard:

1. Open Veeam ONE Web Client.
2. Click on the Deployment Projects section on the left.
3. At the top of the list, click Add.

Veeam ONE Web Client will launch the Add Deployment Project wizard.
