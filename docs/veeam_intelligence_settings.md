# Veeam Intelligence Settings


Veeam Intelligence is an Artificial Intelligence based solution integrated into Veeam ONE Web Client.

For details on the Veeam Intelligence feature, see [Veeam Intelligence](veeam_intelligence.md).

To disable Veeam Intelligence or select its operation mode, follow these steps:

1. Open Veeam ONE Web Client.
2. At the top right corner of the Veeam ONE Web Client window, click Configuration.
3. In the configuration menu on the left, click Veeam Intelligence.
4. Select one of the following options:

* Disabled — disables Veeam Intelligence. The feature is immediately removed from the top bar.
* Basic mode — enables Veeam Intelligence basic mode. The feature icon appears in the top bar, allowing administrators to ask questions about Veeam ONE and receive AI-generated answers based on technical documentation, knowledge base articles and Veeam forums.
* Advanced — activates Veeam Intelligence in the advanced mode. Administrators can inquire about Veeam ONE functionality and settings as well as data protection operations and infrastructure state. For details on Advanced mode, see [Veeam Intelligence Advanced Mode](veeam_intelligence.md#AdvancedMode).
