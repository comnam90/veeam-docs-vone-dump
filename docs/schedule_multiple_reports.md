# Scheduling Delivery for Multiple Reports


Instead of scheduling automatic report delivery for separate reports, you can configure scheduled delivery for a number of reports that are included in the same folder.

To schedule delivery for reports in the same folder:

1. Open Veeam ONE Web Client.
2. Open the Saved Reports tab.
3. In the report screen, select a folder for which you want to schedule delivery.
4. At the top right of the hierarchy, click Settings and choose Schedule.

Alternatively, you can right-click the necessary folder and select Schedule in the context menu.

1. In the Report Folder Scheduling Settings window, click Add.

Veeam ONE Web Client will launch the Add Schedule wizard.

1. Configure the schedule and delivery method as described in section [Scheduling](schedule.md).
2. Click Close.
