# Step 6. Perform System Configuration Check


Before proceeding with the installation, the installer will perform system configuration check to determine if all prerequisite software is available on the machine. To learn what software is required for Veeam ONE, see [System Requirements](system_requirements.md).

If some of the required software components are missing, the setup wizard will enable the missing software components and features automatically.
