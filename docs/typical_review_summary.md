# Step 7. Review Installation Summary


At the Ready to Install step of the wizard, review installation configuration to ensure that you have provided correct settings.

If you need to change any settings in the installation summary, click Customize Settings and proceed to [Step 8. Select Architectural Components](typical_select_veeamone_components.md).

Click Install to begin the installation.

[![Veeam ONE Review Installation Summary](images/typical_installation_summary.webp)](images/typical_installation_summary.webp "Veeam ONE Review Installation Summary")

When the installation completes, click Finish to close the wizard.
