# Grouping Expressions Syntax


You can create custom grouping expressions for categories with dynamic groups. In grouping expressions, you can use:

* [Object Properties](properties.md)
* [Operators](operators.md)
* [Functions](methods.md)
* [Keywords](logical.md)
* [Constants](constant.md)

This section describes components that you can use in grouping expressions.
