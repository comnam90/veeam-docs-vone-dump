# Deployment Scenarios


Veeam ONE supports two deployment scenarios:

* All-in-one

The all-in-one deployment scenario is ideal if you want to consolidate the entire product functionality in one place by installing all product architectural components on a single machine. This scenario is preferable for small- to medium-scale deployments.

* Custom

The custom deployment scenario is more suitable if you want to separate client/server roles and install product architectural components on different machines. This scenario is recommended for large-scale deployments. For details on large-scale deployment recommendations, see [Sizing and Scalability Best Practices](scalability.md).
