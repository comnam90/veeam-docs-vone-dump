# Upgrading to Veeam ONE 13


Upgrade to version 13 is supported starting from Veeam ONE version 12 (build #12.0.0.2498).

To upgrade to Veeam ONE 13, follow these steps.

1. [Launch Splash Window](upgrade_launch_splash.md).
2. [Select Component](upgrade_select_component.md).
3. [Accept License Agreements](upgrade_accept_license_agreement.md).
4. [Review Components to Upgrade](upgrade_review_components.md).
5. [Provide License](upgrade_provide_license.md).
6. [Specify Service Account Credentials](upgrade_specify_credentials.md).
7. [Perform System Configuration Check](upgrade_perform_check.md).
8. [Choose Reporting Database](upgrade_reporting_database.md).
9. [Specify Connection Ports](upgrade_ports.md).
10. [Upgrade Analytics Service Agents](upgrade_analytics_service.md).
11. [Begin Upgrade](upgrade_begin.md).
12. [Change Default Certificate](upgrade_change_certificate.md).
13. [Specify Guest OS Credentials for Microsoft Hyper-V VMs](upgrade_set_guest_os_credentials.md).
14. [Apply Available Updates](upgrade_apply_updates.md).
