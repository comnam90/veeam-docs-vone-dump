# Connecting Microsoft Hyper-V Servers


To collect data about Microsoft Hyper-V infrastructure objects, you must configure connections to Microsoft Hyper-V servers in Veeam ONE Web Client. You can connect the following types of servers:

* SCVMM server
* Failover clusters
* Standalone Hyper-V hosts

|  |
| --- |
| Note: |
| If you plan to connect an SCVMM server, make sure that SCVMM Admin Console is installed on the machine where you installed the Veeam ONE Server component. The version of the SCVMM Admin Console must be the same as the version of SCVMM server you are adding. For details, see [System Requirements](system_requirements.md). |

To configure a connection to a Microsoft Hyper-V server, take the following steps.

1. [Launch the Add Server wizard](hyperv_server_launch.md).
2. [Choose server type](hyperv_server_type.md).
3. [Specify server name and role](hyperv_server_name.md).
4. [Specify credentials](hyperv_server_credentials.md).
5. [Review connection settings](hyperv_server_review.md).
6. [Specify VM guest OS credentials](hyperv_guest_credentials.md).
