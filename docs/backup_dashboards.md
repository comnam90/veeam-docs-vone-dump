# Veeam Backup & Replication Summary Dashboards


Veeam Backup & Replication summary dashboards serve as the 'launch point' for monitoring the backup infrastructure and data protection operations in the virtual environment. The dashboards reflect the latest state of backup, replication and SureBackup jobs, and help you analyze the performance and configuration of backup infrastructure components.

Veeam ONE Client offers the following types of summary dashboards for Veeam Backup & Replication infrastructure components:

* [Backup Infrastructure Summary](backup_infrastructure_summary.md)
* [Backup Repositories Overview](backup_repositories_overview.md)
* [Backup Repository Summary](backup_repository_summary.md)
* [Backup Proxies Overview](backup_proxies_overview.md)
* [Backup Proxy Summary](backup_proxy_summary.md)
* [WAN Accelerators Overview](backup_wan_accelerators_overview.md)
* [WAN Accelerator Summary](backup_wan_accelerator_summary.md)
* [Tape Servers Overview](backup_tape_servers_overview.md)
* [Tape Server Summary](backup_tape_server_summary.md)
* [Cloud Repositories Overview](backup_cloud_repositories_overview.md)
* [Cloud Repository Summary](backup_cloud_repository_summary.md)
* [Cloud Gateways Overview](backup_cloud_gateways_overview.md)
* [Cloud Gateway Pool Summary](backup_gateway_pool_summary.md)
* [Cloud Gateway Summary](backup_cloud_gateway_summary.md)

To view summary details for a specific backup infrastructure object or segment:

1. Open Veeam ONE Client.

For details, see [Accessing Veeam ONE Components](access.md).

1. In the inventory pane, click Veeam Backup & Replication.
2. In the inventory pane, select the necessary infrastructure level.
3. Open the Summary tab.
