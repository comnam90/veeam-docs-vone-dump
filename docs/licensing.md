# Licensing Veeam ONE


To use the full functionality of Veeam ONE, you must install a license file. If you do not install a license, Veeam ONE operates in the Community (free) edition.

This section describes how Veeam ONE licensing works, including licensed objects, license types and packages, license expiration and grace periods, and license usage reporting. For details on installing and managing the license, see [License Information](license_information.md).
