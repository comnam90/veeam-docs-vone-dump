# Dashboards


Veeam ONE Web Client dashboards provide at-a-glance view on the managed Veeam Backup & Replication and Veeam Backup for Microsoft 365 infrastructure, VMware vSphere and Microsoft Hyper-V environments. You can view dashboards in the web browser, schedule automatic dashboard delivery or integrate dashboards into the intranet web portals, such as Microsoft SharePoint.

Every dashboard includes a set of visual components called widgets. Widgets are visual modules that portray various aspects of the managed environment in the form of charts, graphs or tables. By aggregating several widgets on a single screen, dashboards allow you to focus on critical areas of the managed environment, track dependencies and interrelated aspects.

Veeam ONE Web Client includes a set of predefined dashboards. For detailed description of predefined dashboards, see [Predefined Veeam ONE Dashboards](predefined_dashboards.md).

In addition to predefined dashboards, you can create custom dashboards to meet your requirements. In custom dashboards, you can choose the necessary widgets and specify widget properties.
