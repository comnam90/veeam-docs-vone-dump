# Deleting Dashboards


You can delete dashboards if you no longer need them:

1. Open Veeam ONE Web Client.
2. Open the Dashboards section.
3. At the right edge of the dashboard preview image, expand the Settings menu and click Delete.
4. In the displayed dialog box, click Delete to confirm deletion.
