# Getting Started with Veeam ONE


Veeam ONE Client and Veeam ONE Web Client user interfaces are designed to let you quickly locate the required commands, facilitate monitoring of your infrastructure and speed up the investigation and troubleshooting process. You can also access REST API to query information about Veeam ONE entities and perform basic operations with these entities using HTTP requests and standard HTTP methods. This section describes the basic elements and features of the Veeam ONE Client and Veeam ONE Web Client user interface.
