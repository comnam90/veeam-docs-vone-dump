# Reporting Settings


In the Reporting section, you can customize miscellaneous settings of the Veeam ONE Web Client configuration:

* [Customizing Report Branding](customize_report_branding.md)

In this section, you can replace the default report header with a custom image.

* [Configuring SSRS Server Settings](configure_ssrs_server_settings.md)

In this section, you can specify settings of the Microsoft SQL Server Reporting Services server. These settings will be used for integration with Veeam ONE Web Client.
