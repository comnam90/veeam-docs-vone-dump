# All-in-One Installation


In the all-in-one deployment scenario, all Veeam ONE components are installed on a single machine. For details on this scenario, see [All-in-One Deployment](typical_deployment.md).

To install Veeam ONE using the typical scenario, follow these steps.

1. [Launch Splash Window](typical_launch_splash.md).
2. [Select Component](typical_install_veeamone.md).
3. [Accept License Agreements](typical_accept_license_agreement.md).
4. [Provide License](typical_provide_license.md).
5. [Specify Service Account Credentials](typical_specify_service_account.md).
6. [Perform System Configuration Check](typical_perform_configuration_check.md).
7. [Review Installation Summary](typical_review_summary.md).
8. [Select Architectural Components](typical_select_veeamone_components.md).
9. [Choose Monitoring Database](typical_choose_sql.md).
10. [Choose Reporting Database](typical_choose_postgres.md).
11. [Choose Data Locations](typical_choose_directory.md).
12. [Choose Data Collection Mode](typical_choose_collection_mode.md).
13. [Specify Connection Ports](typical_choose_ports.md).
14. [Review Installation Summary](typical_review_sum_two.md).
15. [Add Veeam ONE Service Account to Veeam ONE Administrators Group](typical_check_admins_group.md).
