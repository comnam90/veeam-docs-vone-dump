# Installing Veeam ONE Client


Veeam ONE Client is the client part that allows users to access Veeam ONE monitoring functionality and work with alarms, dashboards and performance charts.

* In the course of all-in-one installation, Veeam ONE Client is installed with other Veeam ONE components. If you want to provide remote access to Veeam ONE monitoring functionality, you can install additional instances of Veeam ONE Client on user workstations.

* In the course of custom installation, Veeam ONE Client is not installed. To be able to access Veeam ONE monitoring functionality, you must install one or more instances of Veeam ONE Client.

|  |
| --- |
| Note: |
| Mind the following:   * Before installing Veeam ONE Client, make sure that you have already installed the Veeam ONE Server component. * You cannot install Veeam ONE Client using GPO or System Center Configuration Manager (SCCM). |

To install Veeam ONE Client, follow these steps.

1. [Launch Splash Window](monitor_client_launch_splash.md).
2. [Select Component](monitor_client_install_veeamone.md).
3. [Accept License Agreements](monitor_client_accept_license_agreement.md).
4. [Perform System Configuration Check](monitor_client_perform_check.md).
5. [Choose Installation Path](monitor_install_path.md).
6. [Specify Veeam ONE Server Name](monitor_client_specify_server_name.md).
7. [Review Installation Summary](monitor_client_review_summary.md).
8. [Check Veeam ONE Client Settings](monitor_client_check_client_settings.md).
