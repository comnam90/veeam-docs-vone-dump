# Configuring Access for Users with Restricted Permissions


To provide access to Veeam ONE reporting and monitoring features for a user with restricted permissions, perform these steps:

1. [Check Veeam ONE security group membership](check_security_membership.md).
2. [Check requirements to the user account](check_account_requirements.md).
3. [Assign permissions on the VMware vSphere or VMware Cloud Director inventory objects](assign_permissions.md).
4. [Log in to Veeam ONE as the user with restricted permissions](log_in_to_one.md).
