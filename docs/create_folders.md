# Creating Folders


To create a new folder:

1. Open Veeam ONE Web Client.
2. Open the Saved Reports tab.
3. In the reports screen, select My reports.

You can also choose any folder that you have previously created under the My reports node.

1. At the top right of the hierarchy, click the Settings button and choose New folder.

Alternatively, you can right-click the necessary folder name and select New Folder in the context menu.

1. In the New Folder window, specify the name of a new folder and click Create.

The new folder will be added to the My reports hierarchy.
