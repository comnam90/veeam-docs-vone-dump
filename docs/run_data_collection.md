# Running Data Collection Manually


You can run data collection for Veeam ONE Web Client manually. This can be required if you disabled automatic data collection, or if you want to collect data between scheduled collection sessions. Data collection runs on all data sources added to Veeam ONE Web Client. For details on data collection sessions, see [Viewing Data Collection Session Details](view_collection_details.md).

Starting Data Collection

When you start data collection manually, Veeam ONE will collect data from all connected servers.

1. Open Veeam ONE Web Client.
2. At the top right corner of the Veeam ONE Web Client window, click Configuration.
3. In the configuration menu on the left, click Data Collection.
4. Click Advanced actions and choose Start report data collection.

Stopping Data Collection

You can stop a data collection session that was started either manually or by the schedule:

1. Open Veeam ONE Web Client.
2. At the top right corner of the Veeam ONE Web Client window, click Configuration.
3. In the configuration menu on the left, click Data Collection.
4. Click Advanced actions and choose Stop report data collection.
