# Step 1. Pre-create Veeam ONE Database (Optional)


If you do not want to create the Veeam ONE database automatically using the Veeam ONE Setup wizard, you can pre-create it before installing Veeam ONE Server.

For details, see [Creating Veeam ONE Database with SQL Script](create_database_with_sql_script.md).
