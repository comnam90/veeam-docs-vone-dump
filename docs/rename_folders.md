# Renaming Folders


To change a folder name:

1. Open Veeam ONE Web Client.
2. Open the Saved Reports tab.
3. In the report screen, under My reports, select the necessary folder.
4. At the top right of the hierarchy, click Settings button and choose Rename.

Alternatively, you can right-click the necessary folder name and select Rename in the context menu.

1. In the Rename Folder window, specify a new folder name and click Rename.
