# Installing Veeam ONE Web Services


To install Veeam ONE Web Services, follow these steps:

1. [Launch the splash window](advanced_launch_splash_web.md).
2. [Select Component](advanced_install_veeamone_web.md).
3. [Accept License Agreements](advanced_accept_license_agreement_web.md).
4. [Provide License](advanced_license_method_web.md).
5. [Specify Service Account](advanced_specify_sa_web.md).
6. [Perform System Configuration Check](advanced_perform_configuration_check_web.md).
7. [Review Installation Summary](advanced_review_original_web.md).
8. [Select Architectural Components](advanced_choose_components_web.md).
9. [Choose Data Location](advanced_install_path_web.md).
10. [Specify Connection Ports](advanced_choose_ports_web.md).
11. [Specify Veeam ONE Server Connection Details](advanced_connect_server_component.md).
12. [Review Installation Summary](advanced_review_summary_web.md).
