You can perform the following actions with alarms that were triggered by Veeam ONE:

* [View triggered alarms](view_alarms.md)
* [Resolve alarms](resolve_alarms.md)
* [Acknowledge alarms](acknowledge_alarms.md)
* [Approve alarm remediation action](remediate_alarms.md)
* [View alarm history](view_alarm_history.md)
* [Export triggered alarms](export_triggered_alarms.md)

You can also work with alarms from the Veeam ONE Web Client [Alarms Overview](reporter_alarms_overview.md) section.
