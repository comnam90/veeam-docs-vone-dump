# Veeam ONE Service Account


The service account must have Local Administrator and Log on as a service permissions on the machine where Veeam ONE is installed.

|  |
| --- |
| Note: |
| You cannot use the Local System account as the service account during product installation. If you want to use Local System to run Veeam ONE services you can configure it later. For details, see [Changing Veeam ONE Service Account](change_service_account.md). |
