# Veeam ONE Web Client Appearance


You can change the color scheme, color mode and menu display to suit your work environment.

To change the color scheme, color mode and menu display:

1. At the top right corner of the Veeam ONE Web Client window, click Configuration.
2. In the Appearance section of the configuration menu, click:

* Color scheme — choose from green, blue or gray.
* Color mode — choose from Light, Dark or System.
* Left menu — Automatic, Expanded or Collapsed.

1. Click Apply.
