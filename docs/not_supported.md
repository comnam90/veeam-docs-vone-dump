# Limitations


You cannot install the following Veeam ONE components on a Domain Controller: Veeam ONE Server, Veeam ONE Web Services, Veeam ONE Database, Veeam Analytics service.

|  |
| --- |
| Note: |
| Veeam ONE is not currently able to collect guest disk space usage data from Linux VMs running in a Hyper-V environment. |
