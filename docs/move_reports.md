# Moving Reports


You can move saved reports from one folder to another folder in My Reports.

To move a saved report:

1. Open Veeam ONE Web Client.
2. Open the Saved Reports tab.
3. In the report screen, under My reports, select the necessary folder.
4. In the displayed list of reports, click a saved report that you want to move.
5. At the top right of the report parameters, click Settings button and choose Move.

Alternatively, you can right-click the necessary report name and select Move in the context menu.

1. In the Move Report window, choose a new target folder for the report.
2. Click Move.
