# Changing Widget Properties


You can change the way your widgets look on dashboards:

1. Open Veeam ONE Web Client.
2. Open the Dashboards section.
3. Click the necessary dashboard to open it.
4. On the dashboard, select the widget you want to modify.
5. At the top right corner of the widget, expand the menu and click Edit.
6. In the Edit Widget wizard, change the widget settings.

For details, see [Add Widgets to Dashboard](add_widgets.md).

1. Save changes.
