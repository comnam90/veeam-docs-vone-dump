# Creating Custom Dashboards


In addition to predefined dashboards, you can create custom dashboards and add custom widgets to this dashboard. To create a custom dashboard, perform the following steps:

1. [Create a dashboard and specify its settings](create_dashboard.md).

Create a new dashboard, specify its name and description.

1. [Add widgets to the dashboard](add_widgets.md).

Add custom widgets to the new dashboard and specify widget settings.
