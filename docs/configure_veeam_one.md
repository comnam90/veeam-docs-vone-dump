# Configuring Veeam ONE


To start working with Veeam ONE, perform a number of steps for its initial configuration:

1. [Add data sources](connecting_servers.md).

Connect Veeam Backup & Replication, Veeam Backup for Microsoft 365, VMware vSphere, VMware Cloud Director and Microsoft Hyper-V servers.

1. [Choose objects to monitor and report on](choose_object_to_monitor.md).

By default, Veeam ONE collects data for all child objects of connected servers. You can change the data collection scope and choose to monitor and report on only specific hosts, datastores and VMs.

1. [Configure notification settings](configure_notification_settings.md).

Specify notification settings to stay aware of all important events and changes that happen in the virtual and backup environment.

1. [Check data collection schedule for Veeam ONE Reporting Service](data_collection_schedule.md).

Check and if necessary adjust data collection schedule for Veeam ONE reporting capabilities.

1. [Add users to Veeam ONE security groups](security_groups.md).

Add to Veeam ONE security groups users who must have access to Veeam ONE Client and Veeam ONE Web Client functionality.
