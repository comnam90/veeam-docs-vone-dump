# Creating Alarms


If predefined alarms do not cover all important events, conditions or state changes about which you need to be notified, you can create custom alarms.

To create a new alarm, perform the following steps.

1. [Select an alarm object type](alarm_type.md).
2. [Specify general alarm settings](alarm_settings.md).
3. [Specify alarm rules and severity](alarm_rules.md).
4. [Specify alarm assignment](alarm_assignment.md).
5. [Specify alarm actions](alarm_notifications.md).
6. [Configure alarm suppression settings](alarm_suppression.md).
7. [Specify alarm details](alarm_details.md).
8. [Save alarm settings](save_alarm.md).
